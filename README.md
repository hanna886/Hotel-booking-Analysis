# Hotel-booking-Analysis
🏨 Hotel Booking Analysis | Data Visualization with Python
This project explores a hotel booking dataset to uncover trends, patterns, and customer behavior insights using Python. The notebook visualizes key metrics such as booking cancellations, lead time, guest demographics, seasonal demand, and more.

🔍 Key Highlights:
Booking behavior trends across time and hotel types
Cancellation rates and influencing factors
Seasonal patterns in bookings
Demographic insights and guest distribution
City hotel vs. resort hotel comparison

🛠 Technologies Used:
Python 3
Jupyter Notebook
Pandas – for data manipulation
Matplotlib & Seaborn – for data visualization
NumPy – for numerical operations
